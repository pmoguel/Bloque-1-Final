# Bloque-I-Midterm
🧑‍💻 Esfera Interactiva 3D por MOGUEL

¡Hola! Soy MOGUEL, y esta es una visualización 3D interactiva que creé usando Three.js para mi proyecto intermedio. Quería combinar diseño y desarrollo para mostrar la aplicación de materiales PBR (Physically Based Rendering) y la interacción del usuario.

✨ Highlights del Proyecto

Este demo técnico presenta:

    3D: Three.js.

    Diseño Visual: Una paleta de alto contraste con fondo Verde Oscuro, interfaz Amarilla y luces Magenta/Cyan.

    Materiales: Tres texturas PBR intercambiables (Hielo, Papel y Rejilla).

    Interacciones Dinámicas: El objeto reacciona al scroll, al mouse y a los clics, gracias a GSAP.

🕹️ ¡Juega con la Escena!

Prueba las siguientes interacciones:
Acción	Efecto
Scroll	Rota el objeto sobre su eje.
Mover Mouse	Mueve la cámara para una vista dinámica.
Click en el Objeto	El objeto crece y rebota.
Botones	Cambia el material (Textura) del objeto.
MOGUEL	Encuéntrame en Instagram.
